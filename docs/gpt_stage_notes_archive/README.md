# GPT Stage Notes Archive

`GPT_STAGE4_NOTES.md` und `GPT_STAGE5_NOTES.md` waren einmalige Hand-off-Notizen
aus abgeschlossenen Entwicklungs-Runden ("Stage 4"/"Stage 5"), adressiert an
Claude als Review-Empfehlung fuer damals neu ergaenzte Features (Electron
Token-Storage, Backend-Middleware, Login-Guard, Backup/Log-Endpunkte etc.).

Die dort referenzierten Punkte sind laengst umgesetzt bzw. ueberholt; die
Dateien wurden von keinem Workflow, keiner CI-Pipeline und keinem anderen Doc
mehr referenziert. Aus Repo-Root-Hygiene (Roadmap #103) am 2026-07-23 aus dem
Repo-Root hierher verschoben, statt geloescht, da sie noch historischen
Kontext zu den jeweiligen Aenderungen enthalten.

Aktuelle Statusdokumente: siehe `docs/planning/` und `docs/CLAUDE_HANDOFF.md`.
